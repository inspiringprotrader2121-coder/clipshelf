ClipShelf

A lightweight clipboard history manager for Windows.

ClipShelf is a free, open-source utility that records everything you copy into a local, searchable history. No cloud sync, no account, no telemetry. The core engine, Python API and command line are ready today; the tray app with its hotkey popup is in development.

Features

  • Clipboard history with configurable size limit and smart dedupe
  • Fuzzy search across your whole history, ranked by match quality, recency, pins and copy counts — plus regex search
  • Pin important clips so they survive history rotation
  • Regex ignore rules keep secrets and noise out of history
  • Named snippets with {date} and {time} placeholders
  • Export to JSON, Markdown or CSV; import with id-level dedupe; stats and diagnostics
  • 100% local — history lives in a JSON file in your own user profile
  • Zero runtime dependencies — pure Python standard library
