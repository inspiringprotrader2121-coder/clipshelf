# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short:

- Be respectful. Harassment, insults and discrimination are not tolerated.
- Assume good faith. Review code, not people.
- Keep discussions on topic and constructive.

Unacceptable behaviour can be reported by opening an issue or contacting the
maintainer directly. Reports are reviewed and handled confidentially, and
maintainers may remove comments, close threads or block accounts that break
these rules.

The full Contributor Covenant v2.1 text defines the expectations and
enforcement guidelines for this project.
