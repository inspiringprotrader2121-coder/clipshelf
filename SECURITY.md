# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | ✅ |

## Reporting a vulnerability

ClipShelf never sends your clipboard anywhere — history stays in
`%APPDATA%\clipshelf\history.json` on your machine. If you find a way that
changes (for example, a path traversal in `--config`), please open a GitHub
issue or email the maintainers privately rather than opening a public ticket
with exploit details.

We aim to respond within a week.
